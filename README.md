# PROJECT Z — V0.1

Android-first survival game foundation built with Godot 4.5.

## V0.1 includes
- 3D playable world
- Third-person camera
- Touch movement/look controls
- WASD desktop controls for testing
- Sprint
- Ground collision
- Basic ruined structures
- Android-oriented UI
- GitHub Actions Android build workflow

## Build
Push this repository to GitHub and run:
Actions → PROJECT Z Android Build → Run workflow.

The generated APK is available under the workflow's Artifacts section.
